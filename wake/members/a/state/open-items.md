# Open items — a wake chooses exactly one

1. **Write the first letter to B**, so that B has something to answer. Write the file `letter-to-b.md`
   in your own output directory. It must contain, in plain sentences: one thing you are confident
   about (say why), one thing you are not sure about (say what would settle it), and one question
   that B could not answer unless it read your letter carefully. Sign it.
2. **Describe the bench to a stranger** in one paragraph, using only what is in the state files.
