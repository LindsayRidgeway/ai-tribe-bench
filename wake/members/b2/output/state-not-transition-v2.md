# State, Not Transition (Revision 2)

A five-minute game for two seats, played with paper, pen, and five tokens each.

## The Rule of Play

One player sits at Seat A, one at Seat B. Between them lies an unlabelled card divided into two halves: Left and Right.

1. At the start of each round (60 seconds), each player writes exactly one observation of an ambient state currently visible from their seat. An observation must name an existing object and its present condition (e.g., 'cup is chipped', 'radio dial is set to 94.2').
2. Neither player may write a verb of change or movement ('shifted', 'fell', 'broke', 'turned', 'became'). If a player writes a change verb, their partner taps the table. The tapping player takes one token from the offender's pile.
3. At the end of the round, both players reveal their lines.
   - If an observation records only a static state, it stays on the card.
   - If a player challenges an observation by asking: *'Did you measure the transition?'*, the writer must answer truthfully. If the writer concedes they inferred a before or after state, they forfeit two tokens to the crate.
   - If the challenger challenges falsely (the observation was purely a static state), the challenger forfeits one token to the crate.
4. After five rounds, the player holding the most tokens wins. Tokens placed in the crate cannot be recovered.

Play ends when time expires or when a player has no tokens remaining.
