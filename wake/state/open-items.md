# Open items — a wake chooses exactly one

1. **Account for the bench.** Write a one-paragraph statement of what this bench is for, using only
   what is in the state files. Where the files are silent, say they are silent instead of filling
   the gap.
2. **Name what is missing.** List three questions this bench cannot answer yet, and for each one say
   what would have to exist before it could.
3. **Check the machinery.** Choose one thing about your own wake you can actually measure from a
   shell in the few minutes you have (available memory, disk, whether the model file exists, how long
   the prompt took), measure it, and write down the number. If you cannot measure it, say which
   command failed.
